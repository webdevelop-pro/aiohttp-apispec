# Changelog

## 3.1.0 - 2026-08-07

- Support current aiohttp route registration and OpenAPI 3 parameter output.
- Generate valid component references for request examples instead of applying
  the OpenAPI component prefix twice.
- Validate the existing `aiohttp_apispec` decorator and middleware API on
  CPython 3.12 through 3.14 with Marshmallow 4.
- Align the package version, release tag, and distribution artifact on 3.1.0.
